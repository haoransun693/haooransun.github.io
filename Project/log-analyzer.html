异步日志分析系统

多层生成器流水线处理日志文件：逐行读取 → JSON 解析 → 级别筛选 → 聚合统计

🔗 生成器流水线 📊 自动聚合 🎯 级别筛选

项目介绍

本项目采用 生成器 (Generator) 流水线模式处理日志文件。每一层只做一件事： 读取 → 解析 → 筛选 → 聚合，层与层之间通过 yield 传递数据，内存占用极低。 支持按日志级别过滤（DEBUG → CRITICAL），自动跳过无效 JSON 行， 最终按级别统计数量并保留消息样本。适用于日常日志分析、监控告警预处理等场景。

核心亮点

🔗 生成器流水线，内存友好

每一层都是生成器函数，数据逐条 yield 传递，不加载全部文件到内存。

支持 GB 级大日志文件处理，流水线可灵活插拔：需要额外过滤层？加一个生成器即可。

def read_log(filepath):
    with open(filepath, "r") as f:
        for line in f:
            yield line.strip()

def parse_log(lines):
    for line in lines:
        if not line:
            continue
        try:
            yield json.loads(line)
        except json.JSONDecodeError:
            pass

🎯 灵活级别筛选

支持 5 级日志：DEBUG → INFO → WARNING → ERROR → CRITICAL。

通过 min_level 参数控制最低级别，例如设为 WARNING 时自动过滤掉 DEBUG 和 INFO 日志。

def filter_level(parsed, min_level="WARNING"):
    levels = {
        "DEBUG": 0,
        "INFO": 1,
        "WARNING": 2,
        "ERROR": 3,
        "CRITICAL": 4
    }
    for record in parsed:
        if levels.get(record.get("level", "INFO"), 0) >= levels.get(min_level, 2):
            yield record

📊 自动聚合统计

按日志级别自动统计数量，保留前 3 条 消息样本供查看。

聚合结果以 dict 形式返回，可轻松对接告警系统或可视化仪表盘。

def aggregate(records):
    stats = defaultdict(
        lambda: {"count": 0, "messages": []}
    )
    for r in records:
        lvl = r.get("level", "UNKNOWN")
        stats[lvl]["count"] += 1
        stats[lvl]["messages"].append(
            r.get("message", "")
        )
    return dict(stats)
