项目背景

在传统的农业生产中，农户往往面临病虫害识别难、种植技术咨询渠道少的问题 本项目通过整合 百度Easy DL和Coze (扣子) 强大的工作流编排能力与专属农业知识库， 构建了一个轻量级的小程序问答助手，旨在降低农业技术获取的门槛

📸 病虫害AI识别

基于百度EasyDL平台训练专属农作物病虫害分类模型，针对水稻等作物病害进行优化

在小程序内可直接拍照或上传图片，快速识别病害名称并返回置信度，实现田间快速诊断

function plant() {

function getToken() {
  wx.request({
    url: 'https://aip.baidubce.com/oauth/2.0/token',
    data: {
      grant_type: 'client_credentials',
      client_id: 'API_KEY',
      client_secret: 'SECRET_KEY'
    },
    success: (res) => this.getResult(res.data.access_token)
  });
}

📚 专属农业知识库

与蜻蜓农服企业合作在 Coze 中整理专业的防治建议。

AI 基于本地知识库进行精准回答，确保建议的科学性和实用性。

Coze 知识库配置:
1. 上传农业 PDF/文档
2. AI 自动向量化索引
3. 用户提问时检索相关知识
4. LLM 结合知识库生成回答

知识库文件:
  水稻病虫害防治手册.pdf
  农药使用指南.docx
  季节性种植建议.txt
