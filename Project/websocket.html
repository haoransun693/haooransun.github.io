WebSocket 实时通信

基于 aiohttp 的 WebSocket 聊天服务端 + 客户端，支持多客户端实时广播消息

🔗 全双工通信 👥 多客户端 📡 实时广播

项目介绍

基于 aiohttp 框架构建 WebSocket 服务端与客户端。服务端维护在线客户端集合， 收到任意客户端消息后，自动广播给其他所有在线客户端，同时显示当前在线人数。 客户端支持收发文本消息，连接断开时自动清理。代码极简（服务端仅 30 行）， 适合作为实时通信、在线客服、协作编辑等场景的基础组件。

核心亮点

👥 多客户端实时广播

使用 set() 维护所有在线 WebSocket 连接，收到消息后遍历集合向其他客户端转发。

每条消息自动携带 当前在线人数（如 "[3人在线] 你好"），让用户感知实时状态。

clients = set()

async def ws_handler(request):
    ws = web.WebSocketResponse()
    await ws.prepare(request)
    clients.add(ws)

    async for msg in ws:
        for c in clients:
            if c != ws and not c.closed:
                await c.send_str(
                    f"[{len(clients)}人在线] {msg.data}"
                )

    clients.discard(ws)
    return ws

🔌 连接生命周期自动管理

新客户端连接时自动加入集合，断开时使用 discard() 安全移除，不会因重复移除而抛异常。

广播前检查 closed 状态，确保不会向已断开的连接发送消息。

# 连接时自动加入
clients.add(ws)

# 断开时安全移除
clients.discard(ws)  # discard不会抛异常

# 广播前检查连接状态
if not c.closed:
    await c.send_str(msg)

📦 极简代码，高可读性

服务端核心逻辑仅 30 行，无外部依赖的复杂配置，开箱即用。

客户端代码同样简洁，可作为 WebSocket 通信的 教学范例 或生产级组件的起点。

# 服务端启动
app = web.Application()
app.router.add_get("/ws", ws_handler)
web.run_app(app, port=8080)

# 客户端连接
async with session.ws_connect(
    "ws://localhost:8080/ws"
) as ws:
    await ws.send_str("你好")
    async for msg in ws:
        print(msg.data)
