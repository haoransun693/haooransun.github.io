多城市天气聚合器

并发查询全国 8 个主要城市实时天气，Semaphore 限流，结果自动存 CSV 并用 pandas 分析

⏱ 并发查询 🔒 Semaphore 限流 📊 pandas 分析

项目介绍

本项目使用 httpx 异步 HTTP 客户端 + asyncio 事件循环， 并发查询北京、上海、广州、深圳、杭州、南京、成都、武汉 8 个城市实时天气。 通过 Semaphore(3) 限制同时进行的请求数量，避免触发 API 限流。 查询结果自动保存为 CSV 文件，并用 pandas 进行统计分析和可视化。

核心亮点

⏱ 异步并发 + Semaphore 限流

使用 asyncio.Semaphore(3) 控制同时最多 3 个请求并发，避免瞬间大量请求导致 IP 被封或 API 限流。

8 个城市总耗时 ≈ 最慢一个请求的时间，而不是排队 8 倍时间，效率提升 3-5 倍。

async def fetch_one(client, city):
    async with sem:  # 最多3个并发
        resp = await client.get(
            "https://api.seniverse.com/v3/weather/now.json",
            params={"key": API_KEY, "location": city}
        )
        data = resp.json()["results"][0]
        return {
            "城市": data["location"]["name"],
            "天气": data["now"]["text"],
            "温度": data["now"]["temperature"]
        }

📊 数据持久化 + pandas 分析

查询结果自动保存为 weather_report.csv，编码为 utf-8-sig 保证 Excel 正常打开。

配套 analyze.py 脚本：自动统计成功/失败数量、计算平均温度/最高温/最低温，方便后续可视化或报表生成。

results = await asyncio.gather(*tasks)
df = pd.DataFrame(results)
df.to_csv("weather_report.csv",
          index=False,
          encoding="utf-8-sig")

# analyze.py
df = pd.read_csv("weather_report.csv",

print(f"平均温度: {df['温度'].mean():.1f}°C")
print(f"最高温度: {df['温度'].max():.1f}°C")

🛡 完善的错误处理

单个城市查询失败不影响其他城市：异常时自动记录失败信息（城市名 + 错误原因），保证整体流程不中断。

实际应用场景中可直接扩展为 50+ 城市，只需修改城市列表即可。

async def fetch_one(client, city):
    try:
        async with sem:
            resp = await client.get(...)
            return resp.json()["results"][0]
    except Exception as e:
        return {
            "城市": city,
            "天气": "失败",
            "温度": str(e)
        }
